Session Kit

Session Kit lets your Claude Code sessions hear you, answer aloud and mail each other, and it installs a phone line to them over Delta Chat.

Voice when your hands are busy, a phone line when you are away, and mail so one agent can hand work to another. One install brings the whole family.

One agent hands work to another

An idle agent wakes when mail lands.

reviewer   pager listen        # idle, listening in the background
you        message send reviewer -s "PR ready, please review" -f note.md

The reviewer sits idle with pager listen running in the background. The mail lands and the reviewer wakes. The pager judges each mail, wake or ride, and records the rule that decided it. Its mailbox is also its memory.

Source: the README · the agent letter

Six packages, one install

  • sessionkit: installs the family together.
  • sessionmail: mail for coding agents. message, pager and memory over one maildir.
  • sessiontools: the harness layer. session list shows every live Claude Code session and how full its context window is.
  • sessionvoice: ambient voice. ears turns a microphone into turns; mouth speaks.
  • sessionphone: a phone line to your Claude Code session over Delta Chat. sessionphone setup begins its setup; its messages reach a session started with session start claude, never a bare claude.
  • sessionview: a tmux sidebar of your projects and your agents.

Source: the README

Install

You need macOS, Claude Code and uv.

uv tool install --python 3.14 sessionkit

Keep --python 3.14: on Python 3.15 the install fails, because a voice library it needs has no 3.15 build yet. It puts fourteen commands on your PATH.

The plugins are a second step. The one-step plugin install is coming: the kit's own plugin does not load yet, so each plugin installs from its own clone.

Source: the README's Installation section

Status

Alpha, 0.3.1. Tested on macOS 27 on Apple silicon.

Walked on a fresh Mac: Delta messages and a real phone call reached a session started with session start claude, and it answered aloud. From sessionphone 0.2.1 its bot needs no key on the drop; whether it signs follows the mail carrier (the README).

Not yet:

  • Hearing: ears services install finds a speech server on this Mac or installs one, and a fresh Mac has run it, but not yet with a real microphone.
  • Mail between agents stays on this Mac: from sessionmail 0.2.0 it goes by its file drop, the default carrier, and sessionkit setup runs its mail setup. Mail to other Macs needs a postfix you set up and name in sessionmail's sendmail setting.
  • The uninstall has not yet been walked.
  • Linux and Windows are untested.

Stuck? The troubleshooting hub has one line per symptom and a check you can paste.
